# DALAN initial preview acceptance checks

- [ ] The homepage shows `Development preview` and `Demo only` labels.
- [ ] Mobile inputs and buttons fit small screens.
- [ ] The route request does not claim any route, fare or travel time is verified.
- [ ] `/api/health` responds with `status: ok`, `phase: development` and `liveTransportData: false`.

- [ ] Vercel Authentication protects all deployment URLs.
- [ ] No DALAN environment variables or database secrets are committed to Git.
